# FHRE (Feather Hybrid Rendering Engine) 架构设计文档

## 1. 整体架构

FHRE 是一个混合渲染引擎，基于 Bevy 的 ECS 架构与 3D 渲染能力，融合了轻量级 UI 绘制能力，旨在为嵌入式和轻量级设备提供高性能、多功能的图形渲染解决方案。

### 1.1 核心设计理念

- **混合渲染**：同时支持 2D UI 绘制和 3D 场景渲染
- **ECS 架构**：采用实体组件系统，提高性能和灵活性
- **GPU/CPU 混合调度**：智能分配渲染任务，最大化硬件利用率
- **跨平台**：支持多种平台和渲染后端
- **可配置性**：通过配置文件调整功能和资源使用
- **现代化 API**：基于 ECS 的现代化 API 设计

### 1.2 目标应用场景

| 场景类型 | 描述 | 技术需求 |
|---------|------|--------|
| **嵌入式 UI** | 控制面板、智能设备界面 | 轻量级、响应式、低资源占用 |
| **2D 游戏** | 休闲游戏、益智游戏 | 2D 渲染、动画、输入处理 |
| **2.5D 游戏** | 卡牌游戏、策略游戏 | 等角投影、深度排序、骨骼动画 |
| **3D 应用** | 简单 3D 场景、数据可视化 | 基础 3D 渲染、相机控制 |
| **混合应用** | 游戏 UI、数据仪表盘 | 2D/3D 混合渲染、UI 组件 |

## 3. 核心组件设计

### 3.1 ECS (实体组件系统)

ECS 是 FHRE 的核心架构，负责管理游戏对象和 UI 元素：

#### 3.1.1 核心概念

- **实体 (Entity)**：唯一标识符，不包含数据
- **组件 (Component)**：纯数据结构，存储实体状态
- **系统 (System)**：处理逻辑，通过查询访问和修改组件
- **查询 (Query)**：访问符合条件的实体和组件
- **资源 (Resource)**：全局共享数据

#### 3.1.2 组件类型

| 组件类型 | 描述 | 用途 |
|---------|------|------|
| **Transform** | 位置、旋转、缩放 | 空间变换 |
| **Render2D** | 2D 渲染数据 | 2D 绘制 |
| **Render3D** | 3D 渲染数据 | 3D 绘制 |
| **UIComponent** | UI 特定属性 | UI 元素 |
| **Animation** | 动画数据 | 动画播放 |
| **Input** | 输入状态 | 输入处理 |
| **PhysicsBody** | 物理刚体属性 | 物理模拟 |
| **Collider** | 碰撞形状 | 碰撞检测 |
| **Camera** | 相机属性 | 视图管理 |
| **Light** | 光源属性 | 光照效果 |
| **Material** | 材质属性 | 渲染效果 |

### 3.2 渲染系统

渲染系统负责图形绘制，支持 2D/3D 混合渲染：

#### 3.2.1 渲染命令

- **RenderCommand**：统一的渲染命令结构
- **命令类型**：2D 绘制、3D 绘制、文本渲染、图像渲染
- **批处理**：合并相同状态的渲染命令

#### 3.2.2 渲染后端

| 后端类型 | 描述 | 适用场景 |
|---------|------|----------|
| **OpenGL ES** | 硬件加速渲染 | 支持 GPU 的设备 |
| **Vulkan** | 现代硬件加速 | 高端设备 |
| **Software** | 软件渲染 | 无 GPU 设备 |
| **Metal** | iOS/macOS 硬件加速 | Apple 设备 |

#### 3.2.3 GPU/CPU 混合调度

- **智能任务分配**：根据任务特性分配到 GPU 或 CPU
- **批处理优化**：合并相同状态的渲染命令
- **负载均衡**：根据硬件能力调整任务分配

UI 系统提供丰富的 UI 组件：

### 3.4 输入系统

输入系统处理用户输入，支持多种输入设备：

#### 3.4.1 输入类型

- **触摸输入**：触摸屏幕
- **键盘输入**：物理键盘或虚拟键盘
- **鼠标输入**：鼠标移动和点击
- **游戏手柄输入**：游戏控制器

#### 3.4.2 事件系统

- **事件类型**：点击、拖动、释放、按键等
- **事件分发**：将事件分发给目标对象
- **事件冒泡**：事件从子对象向父对象传递
- **事件回调**：自定义事件处理函数

### 3.5 动画系统

动画系统处理各种动画效果：

#### 3.5.1 动画类型

- **属性动画**：对象属性的动画（位置、旋转、缩放等）
- **骨骼动画**：角色骨骼动画
- **粒子动画**：粒子系统动画
- **UI 动画**：UI 元素的过渡效果

#### 3.5.2 动画控制

- **播放控制**：开始、暂停、停止、重置
- **时间控制**：速度、延迟、循环
- **混合模式**：动画之间的混合
- **事件触发**：动画关键帧事件

### 3.6 物理引擎

物理引擎提供真实的物理模拟：

#### 3.6.1 核心功能

- **刚体物理**：碰撞检测、力的应用、运动学
- **碰撞形状**：盒形、圆形、多边形、胶囊体
- **约束系统**：关节、弹簧、马达
- **物理世界**：重力、摩擦力、空气阻力

#### 3.6.2 集成方案

| 物理引擎 | 描述 | 适用场景 |
|---------|------|----------|
| **Box2D** | 2D 物理引擎 | 2D 游戏、UI 交互 |
| **Bullet** | 3D 物理引擎 | 3D 游戏、复杂物理模拟 |
| **PhysX** | NVIDIA 物理引擎 | 高性能 3D 物理 |
| **Jolt** | 现代物理引擎 | 高性能物理模拟 |

### 3.7 3D 系统

3D 系统负责 3D 场景的管理，包括相机、场景图和光照：

#### 3.7.1 相机系统

- **相机类型**：
  - **Perspective Camera**：透视相机，用于 3D 场景
  - **Orthographic Camera**：正交相机，用于 2D 场景
  - **Isometric Camera**：等角相机，用于 2.5D 场景
- **相机控制**：
  - **位置控制**：设置相机位置
  - **旋转控制**：设置相机朝向
  - **视野控制**：设置相机视野
  - **投影矩阵**：管理投影变换
  - **视锥剔除**：优化渲染性能

#### 3.7.2 场景管理

- **场景图**：管理 3D 对象的层次结构
- **空间划分**：优化碰撞检测和渲染
- **LOD 系统**：根据距离调整细节

#### 3.7.3 光照系统

- **光源类型**：方向光、点光源、聚光灯
- **阴影效果**：硬阴影、软阴影
- **光照计算**：漫反射、镜面反射

#### 3.7.4 布局系统

- **2D 布局**：
  - **Flex 布局**：弹性布局
  - **Grid 布局**：网格布局
  - **Absolute 布局**：绝对定位
  - **Responsive 布局**：响应式布局
- **3D 布局**：
  - **空间布局**：3D 空间中的对象排列
  - **层级布局**：基于深度的布局

#### 3.7.5 2D 对象的 3D 属性

- **默认 3D 属性**：2D 对象默认位于 XY 平面
- **Z 轴位置**：控制绘制顺序
- **旋转**：支持 3D 旋转
- **缩放**：支持 3D 缩放
- **变换矩阵**：统一的 4x4 变换矩阵

### 3.8 资源系统

资源系统管理各种资源：

#### 3.8.1 资源类型

- **纹理**：图像资源
- **字体**：文本字体

## 4. 架构设计特点

### 4.1 混合架构

- **ECS 架构**：提供现代化的 ECS API，适合游戏开发
- **统一 3D 基础**：所有对象都具有 3D 属性，2D 是 3D 的特例

### 4.3 跨平台

- **平台抽象层**：屏蔽平台差异
- **驱动接口**：统一的驱动接口
- **可移植性**：易于移植到新平台
- **支持的平台**：Linux、Windows、macOS、RTOS、裸机等

### 4.4 可扩展性

- **插件系统**：支持第三方插件
- **模块系统**：可按需启用或禁用模块

- **渲染后端**：可添加新的渲染后端

## 6. API 设计

### 6.1 ECS API

#### CLANG 版本

```c
// 创建实体
fhre_entity_t entity = fhre_entity_create();

// 添加组件
fhre_transform_t *transform = fhre_component_add(entity, FHRE_COMPONENT_TRANSFORM);
transform->position.x = 100;
transform->position.y = 100;
transform->position.z = 0; // 2D 对象默认 z=0

fhre_render2d_t *render = fhre_component_add(entity, FHRE_COMPONENT_RENDER2D);
render->texture = texture;

// 定义系统
void update_position(fhre_world_t *world) {
    fhre_query_t query = fhre_query_create(world, FHRE_COMPONENT_TRANSFORM);
    fhre_entity_t entity;
    while (fhre_query_next(query, &entity)) {
        fhre_transform_t *transform = fhre_component_get(entity, FHRE_COMPONENT_TRANSFORM);
        transform->position.x += 1;
    }
    fhre_query_destroy(query);
}

// 注册系统
fhre_system_t *system = fhre_system_create(update_position);
fhre_world_add_system(world, system);
```

#### RUST 版本

```rust
use fhre::prelude::*;

// 定义组件
#[derive(Component)]
struct Position {
    x: f32,
    y: f32,
    z: f32, // 2D 对象默认 z=0
}

#[derive(Component)]
struct Velocity {
    x: f32,
    y: f32,
    z: f32,
}

// 定义系统
fn move_system(mut query: Query<(&mut Position, &Velocity)>) {
    for (mut position, velocity) in &mut query {
        position.x += velocity.x;
        position.y += velocity.y;
        position.z += velocity.z;
    }
}

// 创建应用
fn main() {
    App::new()
        .add_system(move_system)
```

## 10. 结论

FHRE 是一个创新的混合渲染引擎，基于 Bevy 的 ECS 架构与 3D 渲染能力，融合了轻量级 UI 绘制能力。它的设计目标是为嵌入式和轻量级设备提供高性能、多功能的图形渲染解决方案。

FHRE 的核心优势包括：

1. **混合架构**：同时支持 2D UI 和 3D 场景渲染，2D 对象默认具有 3D 属性
2. **ECS 设计**：提供高性能、灵活的实体管理
3. **GPU/CPU 混合调度**：智能分配渲染任务，最大化硬件利用率
4. **完整的 3D 支持**：包括 3D 渲染、相机系统、光照系统和空间管理
5. **物理引擎集成**：提供真实的物理模拟
6. **跨平台**：支持多种平台和渲染后端
7. **可配置性**：通过配置文件调整功能和资源使用
8. **声明式 UI**：采用现代化的声明式 UI 风格，与 Bevy 保持一致
9. **现代化 API**：基于 ECS 的现代化 API 设计

通过分阶段实现和持续优化，FHRE 有望成为嵌入式和轻量级设备的理想图形渲染解决方案，为开发者提供一个强大而灵活的工具，用于构建各种类型的应用，从简单的 UI 界面到复杂的游戏场景。
