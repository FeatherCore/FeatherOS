# Wing shell resource manifest v1.
#
# These assets are the concrete runtime resources used by the Wing shell.
# The Cargo build script packs them into generated/wing_manifest.bin and
# generated/wing_payload.bin, then the NuttX sim ROMFS copies those binaries
# to /etc/wing.
#
# Runtime SVG icons live under fs/icons/shell/*.svg and are copied to
# /etc/wing/resource/icons/shell/*.svg. icons/bootstrap/*.svg remains the
# built-in fallback source. Icons are parsed by Wing's SVG store/cache and are
# not packed as bitmap resources.
